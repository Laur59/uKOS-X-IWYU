# Repository paths that every third-party library build reads, besides its own
# directory. One path per line, relative to the root of the checkout; a
# directory stands for everything under it, and '*' matches across directories.
#
# Tools/Developer/third-parties-cache hashes these, together with
# Third_Parties/<lib> and Third_Parties/<lib>/cache-inputs.txt, into the key
# that identifies a prebuilt Library/<lib>. 'third-parties-cache audit' reports a
# file the build reads that no list covers.
